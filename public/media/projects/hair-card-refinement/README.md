# Hair-card project media

Replace the visual placeholders with project-owned media using descriptive filenames:

- `hero-before.png` — coarse explicit cards, matched view
- `hero-after.png` — constrained refinement, matched view
- `appearance-only-failure.png` — joint appearance optimization failure
- `production-constrained-result.png` — valid constrained result
- `heldout-before.png` and `heldout-after.png` — held-out comparison
- `method-overview.svg` — optional final pipeline figure
- `turntable.mp4` — optional H.264 MP4, muted loop
- `result-animation.gif` — optional lightweight fallback

After adding files, update paths and alt text in `src/data/siteData.js`. Do not publish confidential datasets or unpublished evidence without checking permissions.
